# 考试自动化系统使用说明

正常使用时只需要双击程序、填写配置表和在图形窗口中操作，不需要手动打开终端。

## 第一次安装

1. 把 `setup_new_pc.cmd` 放到准备安装项目的位置。
2. 双击 `setup_new_pc.cmd`。
3. 等待程序自动安装所需环境并下载项目。
4. 安装完成后，项目位于安装脚本旁的 `examworker` 文件夹。
5. 打开 `examworker`。需要出题时双击 `question_workflow_gui.pyw`；需要创建、编辑或发布考试时双击 `exam_editor_gui.pyw`。

以后需要更新程序时，再次双击原来的 `setup_new_pc.cmd` 即可。

## 准备考试配置

打开 `考试配置表.xlsx`，在“考试设置”中填写：

- 考试名称
- 课程名称、课程 ID 和学期 ID
- 参与班级
- 考试开始时间和结束时间
- 计划成绩发布时间

时间使用北京时间并精确到分钟。计划成绩发布时间必须晚于考试结束时间。

使用 AI 出题时，“选题明细”可以暂时留空。使用已有课程题库题目时，在“选题明细”中填写章节、章内题号、题干关键词和分值。

保存并关闭配置表后，再打开对应的图形程序。

## 后台运行网页

出题程序和考试编辑程序都提供“后台运行网页”选项。

- 不勾选：显示 DeepSeek 和教学平台的 Edge 窗口，适合第一次使用。
- 勾选：网页在后台运行，不占用当前桌面。
- 如果登录尚未完成或登录已经失效，程序会自动弹出可见的 Edge 登录页面，最多等待 6 分钟。
- 登录完成后，程序会自动恢复后台运行并从原步骤继续。

无论是否勾选后台运行，正式发布考试前都会弹出当前考试页面，供用户浏览和核对。

## AI 出题和审核

1. 填写并保存项目目录下的 `考试配置表.xlsx`。
2. 双击 `question_workflow_gui.pyw`，程序会直接打开“AI 出题要求”面板。
3. 填写第一组题目的章节、知识点、题型、难度、数量、分值和补充要求。
4. 如果本次考试只需要这一组题，直接点击“生成题目并进入审核”。
5. 如果还需要其他章节、题型或知识点的题，点击“加入出题清单”，再填写下一组要求。中间各组加入清单后，最后一组可以直接留在填写区；点击生成时会一并处理。
6. 点击“生成题目并进入审核”。程序会按清单逐组生成，并把全部题目汇总到同一次考试中。
7. 如果 DeepSeek 需要登录，程序会自动弹出 Edge。完成登录后程序会自动继续。
8. 在审核窗口逐题检查题干、答案、解析和分值。需要修改时先修改，再点击“通过”。
9. 最后一题通过后，审核窗口会自动关闭，并开始逐题上传课程题库。

审核完成后不需要再次确认上传。程序会按每道题的章节连续上传，并自动记录平台题目和章内位置。上传期间不要关闭出题程序或自动打开的 Edge。

全部上传完成后，出题程序会显示当前考试、题目数量、审核进度、上传进度和当前状态。此时可以关闭出题程序。

## 创建并发布考试

1. 双击 `exam_editor_gui.pyw`。
2. 确认配置表正确，当前状态为 `uploaded`，然后点击“创建并运行考试”。
3. 如果教学平台要求登录，请在打开的 Edge 中完成登录。
4. 程序会创建考试、选择本次题目、设置分值、填写“随堂小测”描述并保存草稿。
5. 发布前会弹出当前考试页面，可以浏览题目、时间、班级和其他考试信息。
6. 同时会显示“人工确认发布考试”窗口。
7. 核对考试名称、班级、开始时间、结束时间和题目数量。
8. 在确认框中输入窗口要求的完整文字，然后点击“确认发布”。

点击“取消，保留草稿”不会发布考试。以后可以再次打开 `exam_editor_gui.pyw`，点击“继续发布草稿”重新核对并发布。

发布成功后，程序会自动创建成绩和答案发布任务，不需要继续等待，也不需要保持考试编辑程序开启。

## 到时自动发布成绩和答案

到达配置的成绩发布时间后，系统会自动：

1. 核对考试编号和考试截止时间。
2. 发布成绩。
3. 打开“公布试卷及答案”。
4. 勾选“全部公布”并开启本次班级。
5. 保存后刷新页面，再次确认设置仍然有效。

系统不会因为存在未提交学生或没有待审核学生而跳过发布。

计划发布时间到达时，电脑需要开机、已登录当前 Windows 用户并连接网络。如果电脑当时关机或睡眠，之后开机并登录时会尽快补执行。

如果自动发布失败，系统会显示“定时发布答案失败”，并打开一个手动发布终端。核对失败原因后，在终端输入 `yes` 并按 Enter，程序才会重新运行与计划任务相同的成绩、试卷及答案发布脚本。输入其他内容不会发布。

## 登录和异常恢复

- 第一次使用或登录失效时，程序会自动弹出对应的 Edge 登录页面。
- 程序会等待用户登录，最长等待 6 分钟。登录完成后不要关闭 Edge，程序会自动继续并在需要时恢复后台运行。
- 如果不想继续当前流程，可以关闭登录用的 Edge 窗口；程序会停止并显示错误，不会继续操作考试。
- 如果上传某道题的结果无法确认，程序会停止，避免重复上传。请先到课程题库核对该题。
- 如果创建考试时取消发布，草稿和当前进度都会保留，可点击“继续发布草稿”。
- 如果计划任务执行时登录失效，程序会弹出 Edge 并等待登录；超过 6 分钟仍未完成时，会转入上述手动发布终端。
- 不要随意删除 `work` 文件夹、当前考试状态文件或配置表，否则程序可能无法识别已经上传、创建或发布的内容。

## 日常操作顺序

使用 AI 出题：

1. 填写并保存考试配置表。
2. 双击 `question_workflow_gui.pyw`。
3. 填写一组或多组出题要求并开始生成。
4. 完成人工审核，等待自动上传结束。
5. 关闭出题程序，双击 `exam_editor_gui.pyw`。
6. 点击“创建并运行考试”。
7. 核对信息并确认发布。

使用课程题库中已有题目：

1. 在配置表中填写“选题明细”。
2. 双击 `exam_editor_gui.pyw`。
3. 点击“检查配置”。
4. 点击“创建并运行考试”。
5. 核对信息并确认发布。
